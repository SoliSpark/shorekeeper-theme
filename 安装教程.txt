DeepSeek Harness · 守岸人主题（Shorekeeper Theme）
版本 1.2.0 · 适用 DSH 0.2.1-rc.2（Windows 桌面版）

============================================================
一、这个文件夹是什么
============================================================
一个 DSH（DeepSeek Harness）客户端插件，包含：
  · 启动动画：线稿逐笔绘制 → 睁眼 → 文字/标识动画 → 粒子消散过渡
  · 主题背景：默认使用启动动画做成的无缝循环，也可换成自己的图片/视频
  · 侧栏面板：调节界面透明度、背景压暗、背景模糊，重播启动动画
插件运行时不需要联网，影片/线稿/标识都已内嵌在 client.js 里。

============================================================
二、应该安装在哪里
============================================================
1) 插件本体：建议放在一个固定的目录，例如
     D:\DeepSeek Harness\plugins\deepseek-harness-shorekeeper-theme
   不要放进 C:\Users\<你>\.dsh 里面（那是 DSH 的配置目录，清理/升级时容易丢）。
   放好后不要再移动；如果移动了，需要重新执行下面的 add 命令。

2) 安装目标（DSH 的 desktop profile）：
     C:\Users\<你>\.dsh\profiles\desktop
   这个目录由 DSH 自己创建，目录里的 package.json 记录插件依赖和启用列表。

============================================================
三、安装步骤
============================================================
步骤 1：把整个文件夹放到上面建议的位置（路径按你的实际情况改）。
        路径中不要有特殊字符；中文路径一般也可以。

步骤 2：打开 PowerShell，执行（二选一）：

  A. 用 DSH 桌面版自带的命令行（推荐，适合 dsh 不在 PATH 的情况）：
     & "D:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "link:D:\DeepSeek Harness\plugins\deepseek-harness-shorekeeper-theme"

  B. 如果 dsh 已经在 PATH 里：
     dsh plugin --profile desktop add "link:D:\DeepSeek Harness\plugins\deepseek-harness-shorekeeper-theme"

  说明：link: 后面的路径必须是这个文件夹的完整路径。
  成功时最后会显示：
     + @local/dsh-shorekeeper-startup 1.2.0 <- D:\...\deepseek-harness-shorekeeper-theme

步骤 3：确认已启用为 bundle。
  用记事本打开：
     C:\Users\<你>\.dsh\profiles\desktop\package.json
  应能看到类似：
     "dependencies": {
       "@local/dsh-shorekeeper-startup": "link:D:/.../deepseek-harness-shorekeeper-theme"
     },
     "dsh": { "profile": { "bundles": [
       "@deepseek-ai/dsh-base",
       "@deepseek-ai/dsh-web-app",
       "@local/dsh-shorekeeper-startup"
     ] } }
  如果 bundles 里没有 "@local/dsh-shorekeeper-startup"，手动补一行（注意 JSON 逗号），然后保存。

步骤 4：完全退出 DSH。
  窗口关闭不够：请从系统托盘退出，确认进程结束后再重新打开 DSH。

============================================================
四、安装成功的表现
============================================================
  · 启动时全屏播放「线稿 → 睁眼 → 文字/标识」动画，ESC 或点击可跳过；约 9 秒。
  · 左侧栏多出「DeepSeek Harness · 守岸人主题」入口（黑海岸徽记图标）。
  · 点开后可切换背景（启动动画 / 图片 / 视频）、拖动透明度/压暗/模糊滑杆、重播动画。
  · 设置自动保存在本机，刷新或重启后保留。

============================================================
五、卸载
============================================================
1) 执行：
   & "D:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove @local/dsh-shorekeeper-startup
2) 打开 C:\Users\<你>\.dsh\profiles\desktop\package.json，
   把 bundles 里的 "@local/dsh-shorekeeper-startup" 删掉。
3) 重启 DSH。之后即可删除插件文件夹。

============================================================
六、常见问题
============================================================
· 启动后仍是原生界面：检查 package.json 的 bundles 是否包含该插件；
  再确认是否完全退出并重启了 DSH。
· 左侧栏没有入口：插件未加载。用上面的 remove 命令移除后重新 add。
· 想换素材后重新构建：需要 Node.js（DSH 自带即可），在插件目录运行：
     node build.mjs
  会重新把 assets 里的影片/线稿/标识内嵌到 client.js。
· 移动了插件文件夹：旧的 link 路径失效，先 remove 再按新路径 add。
· 动画在部分机器上偏慢：可在 client.template.js 顶部调整 RATE（播放倍速）
  与 CUT_AT / OUT_AT（睁眼与退场时间），改完重新 build。
